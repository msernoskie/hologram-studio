Emotes & AI labels

    

    

      
      
      
      
    

    
Click an emote name to preview it live. Select several
      (checkbox) and “Fire selected” to preview a combo. Type comma-separated
      emotion labels (e.g. joy, excited) — “Apply” writes them into
      Open-LLM-VTuber’s emotionMap so the LLM can use [joy] tags.

Hand gestures

    

      
      Face tracking is always on either way — this only controls
        whether hand poses can do anything.
    

    

    

      
      
      
      
    

    
Finger count is what's detected (which fingers doesn't
      matter; thumbs never count). Remaps apply live — the sidecar reloads the
      file on change. nudge steps the way the finger points, so it only makes
      sense on 1 finger. Sequences from the panel above are assignable too — a gesture
      can play one. The hold row is the long-press action (default: fist 3 s
      = restore home, the blind panic button).

  


  
  

    
AI backend

    

      
      
      
      
    

    

      
      
      
    

    
Points Open-LLM-VTuber's LLM at a server — e.g. the oobabooga VM
      (openai_compatible_llm) or local Ollama (ollama_llm).
      Changes land in conf.yaml and need a backend restart (button above —
      also reloads the hologram, ~15 s).

Character cards

    

    
Cards are saved presets (name + persona). Apply loads one into
      the fields and writes it to conf.yaml; restart the backend to make it live.
      Emotion tags from the labels panel are appended to the prompt automatically by
      Open-LLM-VTuber — the persona doesn't need to list them.
