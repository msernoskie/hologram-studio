OpenGhost — Hologram Studio

Models

Click to switch — restarts the backend and reloads the hologram (takes ~15 s). Expression files are auto-registered on every switch.

Add model

A Cubism 3+ model archive (zip/rar/7z — VTube Studio exports work). Automatically: extracts, finds the model, downscales textures over 4096 px (bigger renders invisible on the Pi's GPU), registers its expressions, and adds it to the model list.

Emotes & AI labels

    

    

      
      
      
      
      
    

    
Click an emote name to preview it live; tick several and
      “Fire selected” to preview a combo (previews only — sequences are built in
      the next panel). Type comma-separated emotion labels (e.g. joy, excited)
      — “Apply” writes them into Open-LLM-VTuber’s emotionMap so the LLM can use
      [joy] tags.

Hand gestures

    

      
      Face tracking is always on either way — this only controls
        whether hand poses can do anything.
    

    

    

      
      
      
      
    

    
Finger count is what's detected (which fingers doesn't
      matter; thumbs never count). Remaps apply live — the sidecar reloads the
      file on change. nudge steps the way the finger points, so it only makes
      sense on 1 finger. Sequences from the panel above are assignable too — a gesture
      can play one. The hold row is the long-press action (default: fist 3 s
      = restore home, the blind panic button).

  


  
  

    
Chat 

    

      
      
      Messages go through the hologram's own session — she
        emotes on the display, subtitles show her reply, and it all lands in
        the same history as voice chat.
    

    

    

      
      
    

    

      
    

    

      
      
      
      
    

    
The greeting fires when the camera sees your face again
      after that long away (and you stay ~2s — walking past doesn't count).
      It's sent as a hidden instruction through the normal chat pipeline, so
      she greets you in character.

  


  
  

    
Idle motions

    

      
      Master switch for everything below plus the idle
        figure-8 sway. Face tracking and gestures are unaffected either way —
        off just means she rests centred and still between interactions.
    

    

    

      
      
    

    
Each row is one recurring motion: the part it moves,
      how strong, seconds per pulse, the possible burst sizes
      (comma-separated — one is picked at random each time, e.g. 1,3),
      and the random rest range between bursts. All motions pause while she talks,
      none of them ever move her position/framing, and parts a model doesn't have
      are silently skipped. Applies live on save.

  


  
  

    
AI backend

    

      
      
      
      
    

    

      
      
      
    

    
Points Open-LLM-VTuber's LLM at a server — e.g. the oobabooga VM
      (openai_compatible_llm) or local Ollama (ollama_llm).
      Changes land in conf.yaml and need a backend restart (button above —
      also reloads the hologram, ~15 s).

Character cards

    

    
Cards are saved presets (name + persona). Apply loads one into
      the fields and writes it to conf.yaml; restart the backend to make it live.
      Emotion tags from the labels panel are appended to the prompt automatically by
      Open-LLM-VTuber — the persona doesn't need to list them.
